## 它是做什么的

Hermes 很能干（跑命令、读写文件、上网、定时任务……），但平时只能在电脑上敲。
这个 App 把手机接上**你自己的** Hermes：随时发消息、看它怎么想的、用斜杠指令、危险操作先问你。

---

## 主要功能

- **两种连接方式**
  - **API 直连**：填你自己 Hermes 的地址 + 密钥，最快
  - **网关**：登录账号，指令全通（`/compress`、`/context` 这些都能用）
- **多窗口 + 分屏双栏**：两个会话并排，各自独立的**模型**与**连接**，消息可互传
- **完整思考过程**：默认收起显示最新一条，点开看全部
- **斜杠指令**：`/stop`、`/new`、`/model`、`/compress`…（网关模式全通）
- **危险操作审批**：仅单次允许 / 始终允许 / 取消
- **新消息通知** + 回到底部（带未读条数）
- **外观**：主题四选一（跟随系统 / 浅色 / 深色 / AMOLED）、自定义壁纸、毛玻璃

---

## 怎么连上你自己的 Hermes

1. 装好后打开 App → 设置 → 「连接 Hermes」
2. **API 直连**：填你自己 Hermes 的**地址 + API 密钥**
3. **账号绑定**：登录账号系统 → 绑定你自己的 Hermes（下次登录免填）

> 本 App **不内置任何服务器、也不带任何密钥**——连的永远是你自己的那台。
